# Earth's Tipping Points · จุดพลิกผันของโลก

An interactive, rotating dot-globe of the 16 climate tipping elements, in English and Thai.
All points blink at the same moment. Tap or click a point to see what is at risk, what happens,
where it is, and the global-warming threshold at which it may tip.

- Open `index.html` in any browser; it works offline (fonts load from Google Fonts when online).
- `#th` at the end of the address opens the Thai version: `…/index.html#th`
- `#video` / `#video-th` show the full-screen recording layout used for the MP4s.

## Data and references

Thresholds and locations:
Armstrong McKay, D. I., Staal, A., Abrams, J. F., Winkelmann, R., Sakschewski, B., Loriani, S., et al. (2022).
*Exceeding 1.5°C global warming could trigger multiple climate tipping points.* University of Exeter. Journal contribution.
https://hdl.handle.net/10871/131584

2024 update (thresholds unchanged; early-warning signals; Arctic sea ice and large-scale permafrost collapse judged less plausible):
Armstrong McKay, D. I. (2024). Two decades of climate tipping points research: Progress and outlook.
*Dialogues on Climate Change*, 1(1), 30–38. https://doi.org/10.1177/29768659241293272

2025 update (warm-water coral reefs likely past their tipping point):
Lenton, T. M. et al. (2025). *Global Tipping Points Report 2025.* University of Exeter.

Point positions are representative places for each region, read from the map in Armstrong McKay et al. (2022).
Land outline: Natural Earth 1:50m via world-atlas (public domain).

## Publish on GitHub Pages

1. Create a new public repository on GitHub, e.g. `earth-tipping-points`.
2. Upload `index.html` and `README.md` (Add file → Upload files → Commit).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. After about a minute the site is live at `https://<your-username>.github.io/earth-tipping-points/`.
